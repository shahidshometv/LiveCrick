# LiveCrick

Free, cricket-first live TV and sports app for India. See the PRD for full product requirements.

## Repository layout

```
livecrick/
├── app/              Flutter mobile app (Android and iOS)
├── .github/workflows CI pipelines
└── README.md
```

Planned additions: `api/` (NestJS backend) and `admin/` (React dashboard, deploys to Vercel).

## First-time setup (Flutter app)

The repo contains the Dart code and assets. Platform folders (`android/`, `ios/`) are generated by Flutter.

```bash
flutter create --org in.livecrick --platforms android,ios app
```

If `app/` already exists, run `flutter create --org in.livecrick --platforms android,ios .` from inside `app/` instead. Check `git diff` afterwards to confirm your `lib/` and `pubspec.yaml` were not overwritten.

Then:

```bash
cd app
flutter pub get
flutter run --dart-define=USE_MOCK=true
```

Run against a real API later:

```bash
flutter run --dart-define=USE_MOCK=false --dart-define=API_BASE_URL=https://api-staging.example.com/api/v1
```

## Checks before pushing

```bash
cd app
flutter analyze
flutter test
```

## Uploading to GitHub

1. Create an empty repository on GitHub (no README, no .gitignore).
2. Extract this folder, then from inside it run:

```bash
git init
git add .
git commit -m "Initial LiveCrick scaffold"
git branch -M main
git remote add origin https://github.com/<your-user>/livecrick.git
git push -u origin main
```

## Rights and content policy

Only play streams with documented distribution rights. Never commit stream URLs, DRM keys, or API secrets. The mock channel URL is Apple's public sample stream and is for development only.
